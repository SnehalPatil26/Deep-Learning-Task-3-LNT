## Objective

To enhance image datasets using augmentation and preprocessing techniques and analyze their impact on deep learning model performance and generalization.

## Dataset

The **CIFAR-10 image dataset** is used for this task. It contains 50,000 training images and 10,000 testing images. Each image is 32 × 32 pixels with 3 RGB color channels and belongs to one of 10 different classes.
